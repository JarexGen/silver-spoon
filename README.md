# Silver Spoon

A VCMI mod for players who want their heroes spoon-fed.

## Submods

- **Level Scaling** - every level after the first, each hero gains: +20% experience gain, +1 Attack/Defense/Spell Power/Knowledge, +1% double-damage chance, ignore 1% of enemy defense, +2% spell damage, +100 gold per day, +10% land movement and +100 sea movement points (all multiplied by hero level minus one, so a level 1 hero is unchanged). Rough terrain also costs 50 fewer movement points per tile, like Advanced Pathfinding. Heroes whose specialty already gives one of these bonuses keep only their own version of it.
- **Unlimited Secondary Skills** - removes the 8-skill limit.

## Requirements

VCMI 1.7.0 or newer.
